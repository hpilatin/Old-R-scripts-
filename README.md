# These are some of the R scripts that I coded and used during my master’s degree. Although I developed many more scripts for various statistical and spatial analyses of both precipitation and SST simulations as part of my thesis, I could only include some of them here.
# Brief information about the project:
Med refers to the Mediterranean region, while EBLS refers to the Eastern Black Sea region. 
Two model domains were used for each study region: a parent domain with 9 km resolution and a nested child domain with 3 km resolution.
The thesis consisted of two main parts:
    - The first focused on sensitivity analyses of heavy precipitation predictions, with the aim of identifying the model configuration that provided the best overall prediction performance for each study region. 
    - The second focused on sea surface temperature (SST) analyses, in which different external SST datasets were used as model inputs and their performance was evaluated for each region.
